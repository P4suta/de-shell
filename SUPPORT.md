# Support

Use [GitHub Discussions](https://github.com/P4suta/de-shell/discussions) for
installation help, usage questions, interpretation of evidence, and early
design ideas. Include the exact de-shell commit, platform, source shell, and a
sanitized minimal example.

Use the structured issue forms for reproducible defects and concrete feature
contracts. The issue tracker is not a private support channel. Never attach
credentials, proprietary automation, or vulnerability details; follow
[SECURITY.md](SECURITY.md) for private disclosure.

The project is currently experimental and community-supported. There is no SLA,
and platform certification remains limited to the gates described in
[ROADMAP.md](ROADMAP.md).
